# 🎯 Entrenamiento Frontend Junior con React

Este repositorio contiene una serie de **ejercicios prácticos** para prepararte para entrevistas de **Frontend Developer (React Junior)**.  
Incluye ejercicios de **JavaScript ES6**, **React**, **Hooks**, **manejo del DOM virtual** y **consumo de APIs**.

---

## 📂 Secciones

1. Fundamentos de React
2. Manejo de Estado y Props
3. Hooks básicos
4. Renderizado condicional y listas
5. Estilos en React
6. Consumo de APIs
7. Ejercicios completos tipo mini-proyectos

---

## 🟦 1. Fundamentos de React

- [ ] Crear un componente funcional que muestre "Hello React!"
- [ ] Crear un componente `Button` que reciba como prop el texto del botón
- [ ] Crear un componente `Card` con `title` y `description` como props
- [ ] Crear un componente que renderice la fecha actual en pantalla

---

## 🟨 2. Manejo de Estado y Props

- [ ] Crear un contador con botones `+` y `-`
- [ ] Crear un input controlado que muestre en tiempo real lo que el usuario escribe
- [ ] Pasar datos desde un componente padre a un hijo mediante props
- [ ] Crear un toggle que oculte/muestre un párrafo al hacer clic

---

## 🟩 3. Hooks básicos

- [ ] Usar `useState` para crear un formulario simple de login
- [ ] Usar `useEffect` para mostrar en consola un mensaje cuando el componente se monte
- [ ] Usar `useEffect` para actualizar el título del documento (`document.title`) con el valor de un contador
- [ ] Usar `useEffect` para consumir datos de una API pública y mostrarlos en pantalla

---

## 🟧 4. Renderizado condicional y listas

- [ ] Renderizar una lista de nombres a partir de un array
- [ ] Renderizar una lista de objetos con `map`
- [ ] Mostrar un mensaje "No hay elementos" si la lista está vacía
- [ ] Renderizar condicionalmente un componente de `Loading...` mientras se cargan datos de una API

---

## 🟪 5. Estilos en React

- [ ] Aplicar estilos con un archivo CSS externo
- [ ] Aplicar estilos con módulos de CSS
- [ ] Usar `styled-components` para estilizar un botón
- [ ] Cambiar dinámicamente el estilo de un elemento con base en un estado (ejemplo: modo oscuro/claro)

---

## 🟥 6. Consumo de APIs

- [ ] Consumir la API de Pokémon y mostrar los nombres en una lista
- [ ] Crear un buscador que filtre resultados de una API pública
- [ ] Mostrar un spinner de carga mientras llegan los datos
- [ ] Manejar errores de una API (mostrar un mensaje si falla la petición)
